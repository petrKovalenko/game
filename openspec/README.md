# Tactics Slice — вертикальный срез

Реализация change [`add-vertical-slice`](changes/add-vertical-slice/proposal.md): пошаговый тактический бой на сетке под Android/Desktop на Godot 4.

## Запуск

1. Установить [Godot 4.2+](https://godotengine.org/download).
2. Открыть папку проекта (файл `project.godot`) в Godot.
3. Запустить проект (F5) — стартует меню-заглушка → «Начать бой».

## Игра

- Отряд игрока: **Воин** (ближний бой, HP 30) и **Стрелок** (радиус 3, HP 20) против двух **Грунтов**.
- Тап по своему юниту → подсветка зоны перемещения (синие клетки) и панели способностей внизу.
- Тап по синей клетке — перемещение; тап по кнопке способности → тап по красной клетке-цели — атака.
- За ход доступны одно перемещение **и** одно действие; «Завершить ход» пропускает остаток.
- На Desktop тач эмулируется мышью (`emulate_touch_from_mouse`).

## Тесты логики

```sh
godot --headless --path . --script res://tests/run_tests.gd
```

Покрывают: сетку и проходимость, поиск пути, зону достижимости, очередь инициативы (детерминизм по seed), урон способностей, условия победы/поражения, поведение ИИ. Раннер — встроенный headless-скрипт (замена GUT, чтобы не тянуть внешние зависимости в срез); миграция на GUT — добавлением addon без изменения тестов логики.

## Экспорт

Пресеты в [`export_presets.cfg`](export_presets.cfg): Windows Desktop и Android (arm64). Для Android-сборки нужны Android Build Template/SDK и keystore — настраиваются в Godot (Project → Export). Ключевые параметры для устройства уже заданы: landscape-ориентация, stretch `canvas_items`, renderer `mobile`.

## Структура

```
src/logic/   — чистая логика боя (BattleGrid, BattleUnit, TurnQueue, BattleEngine)
src/data/    — декларативные ресурсы юнитов и способностей (.tres)
src/scenes/  — меню, сцена боя (ввод, изо-рендер, UI), представление юнита
tests/       — headless-раннер тестов логики
```

Спецификации: см. [specs](specs/spec.md) (после archive) и дельты change.
