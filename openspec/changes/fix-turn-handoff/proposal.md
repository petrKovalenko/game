# Proposal: fix-turn-handoff

## Why

Баг в вертикальном срезе: после завершения ходов всех противников ход не возвращается к игроку — бой «зависает» на границе раундов. Ввод игрока игнорируется (активный юнит `null`), кнопка «Завершить ход» не отвечает.

**Причина** ([`src/logic/battle_engine.gd`](../../src/logic/battle_engine.gd), `end_turn()`): при переходе к новому раунду [`_start_round()`](../../src/logic/battle_engine.gd:191) сбрасывает `turn_index = -1`, после чего `end_turn()` читает `round_order[turn_index]` с индексом `-1`. В GDScript отрицательный индекс возвращает **последний** элемент массива: сигнал `turn_started` излучается для последнего юнита нового раунда, но [`active_unit()`](../../src/logic/battle_engine.gd:49) возвращает `null` (т.к. `turn_index < 0`). Представление ([`src/scenes/battle.gd`](../../src/scenes/battle.gd:288)) корректно отклоняет такой ход ИИ (`active_unit() != unit`), а ввод игрока требует ненулевого активного юнита — возникает дедлок.

## What Changes

- **Bugfix** в [`src/logic/battle_engine.gd`](../../src/logic/battle_engine.gd): корректная установка `turn_index` при переходе на новый раунд (первый юнит нового раунда получает ход, `active_unit()` согласован с излучаемым сигналом).
- **Тесты**: регрессионный тест в [`tests/run_tests.gd`](../../tests/run_tests.gd) — полный цикл раунда (все юниты походили) → ход переходит к первому юниту нового раунда, `active_unit()` не `null`.
- **Spec**: уточняется требование «Очередь ходов по инициативе» в `tactical-combat` — явно фиксируется переход между раундами и возврат хода игроку после хода противников.

## Capabilities

### Modified

- `tactical-combat`: требование «Очередь ходов по инициативе» дополняется сценариями перехода на новый раунд и возврата хода игроку.

## Impact

- **Specs**: `tactical-combat` (MODIFIED).
- **Code**: только [`src/logic/battle_engine.gd`](../../src/logic/battle_engine.gd) (2–3 строки) + тесты. Представление и данные не затрагиваются.
- **Совместимость**: seed-детерминизм очереди не меняется; сохраняются существующие тесты.
