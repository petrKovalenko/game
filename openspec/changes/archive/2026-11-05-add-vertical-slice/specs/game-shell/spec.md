# game-shell — Delta

## ADDED Requirements

### Requirement: Каркас приложения

Приложение SHALL запускаться в сцену боя из минимального меню-заглушки и корректно завершаться без утечек сцены.

#### Scenario: Запуск боя
- **WHEN** пользователь запускает приложение и выбирает «начать бой»
- **THEN** открывается сцена боя с тестовой картой

#### Scenario: Возврат после боя
- **WHEN** бой завершён и пользователь нажимает «заново» на экране результата
- **THEN** запускается новый бой с исходным состоянием юнитов

### Requirement: Тач-ввод

Приложение SHALL поддерживать тач-ввод как основной: выбор юнита тапом, контекстное действие тапом по клетке, выбор способности через нижнюю панель с зонами нажатия не менее 44 dp.

#### Scenario: Выбор юнита тапом
- **WHEN** игрок тапает по своему юниту
- **THEN** подсвечиваются зона перемещения и доступные цели, внизу появляется панель способностей

#### Scenario: Крупные тач-зоны
- **WHEN** игрок нажимает на элемент панели способностей
- **THEN** способность выбирается при точном попадании в зону не менее 44 dp

### Requirement: Кросс-платформенная сборка

Проект SHALL собираться как минимум в таргеты Android и Desktop из одной кодовой базы без платформо-зависимых вызовов в игровой логике.

#### Scenario: Сборка Android
- **WHEN** выполняется экспорт проекта по Android-пресету
- **THEN** APK собирается и запускается на устройстве со сценой боя

#### Scenario: Запуск на Desktop
- **WHEN** проект запускается на Desktop-таргете
- **THEN** бой играется мышью через тот же обработчик ввода
