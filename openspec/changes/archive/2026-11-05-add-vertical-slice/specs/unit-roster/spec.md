# unit-roster — Delta

## ADDED Requirements

### Requirement: Декларативные определения юнитов

Каждый класс героя и тип врага SHALL описываться декларативным ресурсом, содержащим статы (HP, урон, инициатива), лимит перемещения и список способностей; правка данных SHALL не требовать изменения кода.

#### Scenario: Добавление класса без кода
- **WHEN** создан новый ресурс юнита с валидными статами и способностями
- **THEN** юнит доступен для постановки в бой без изменений исходного кода

#### Scenario: Валидация данных
- **WHEN** ресурс юнита содержит отсутствующее обязательное поле или отрицательное значение стата
- **THEN** загрузка данных завершается ошибкой валидации с указанием поля

### Requirement: Набор способностей юнита

Каждый юнит SHALL иметь минимум одну способность с определёнными радиусом действия и расчётом урона от статов.

#### Scenario: Способность применима в бою
- **WHEN** юнит с валидной способностью выбран в бою и цель в радиусе
- **THEN** способность применяется и урон рассчитывается от статов ресурса

### Requirement: Стартовый состав среза

Срез SHALL включать два класса героя (Воин — ближний бой с высоким HP; Стрелок — дальний бой с меньшим HP) и один тип врага ближнего боя.

#### Scenario: Состав боя по умолчанию
- **WHEN** запускается сцена боя среза
- **THEN** в отряде игрока по одному Воину и Стрелку, против них два врага заданного типа
